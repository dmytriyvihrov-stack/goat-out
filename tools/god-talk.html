This page was opened as a file: every line below is read straight from the game's scripts, to read and edit, and COPY AS JS works, but SAVE cannot write to the disk from here. In a terminal in the project folder run node tools/serve.js 8766, then open http://localhost:8766/tools/god-talk.html (or press TALK in the game's dev drawer while it is served).

What this is: every line the god, the blind shepherd, the death tips, the animals and the mouse say, in one place to reword. Change a line in its box, then SAVE: it is written straight back into the game's code (js/heaven.js, js/tuning.js, js/beasts.js), and the game says it from the next reload.

Every line is one talk; | cuts it into parts, each shown as its own plate in turn. "CUT HERE" puts a cut where the cursor is. {floor} and {animal} are filled in by the game. A part over characters is marked: it wraps to more than three lines on the god's panel. SAVE needs the dev server (node tools/serve.js); away from it, COPY and paste over the two objects in js/heaven.js.

THE ANIMALS · THE MOUSE

Every line an animal (and the mouse) says, read out of js/tuning.js and js/beasts.js. Each line is saved on its own: SAVE rewrites it where it stands in the source, DELETE takes it out of its list (a line that stands alone, like the horse's won, is emptied instead, so nothing that reads it breaks). Needs the dev server; reload the game to hear it.
