# GOAT OUT — молодой козлик и союзники / Pixel 2.5

Актуальная передача r3 от 23.09.2026. Заменяет предыдущий образ козлика. Последняя правка: немного взрослее; серое пятно на спине менее контрастное; длинная фиолетовая молния через анатомически ПРАВЫЙ глаз.

## Исправление пользователя

**Главный герой — молодой GOAT, козлик. НЕ овечка.** Узкое стройное тело, короткая гладкая шерсть, острые уши, чуть удлинённые направленные назад рожки и маленькая бородка, короткий поднятый хвост и тонкие ноги с копытцами. Шерсть цвета слоновой кости, пятно на спине светлое серо-бежевое, без прежнего тёмного контраста. Длинная фиолетовая молния идёт со лба через ПРАВЫЙ глаз вниз по щеке. Спереди (S) это левая сторона картинки. В E/SE видна отмеченная правая щека; в SW/W/NW/N/NE метка скрыта. Не отражать кадры горизонтально для противоположных направлений.

**Мышь-торговец, гусь, ворон и черепашка — союзники.** Не добавлять их в список противников. Пользователь попросил пока по одной маленькой картинке этих животных; для них сделаны одиночные иконки SE, без анимации и остальных поворотов.

**Овечка — только будущий скин домашнего питомца**, без синей/фиолетовой метки, молнии или синяка под глазом. Для неё сохранены 8 чистых idle-ракурсов. Старые анимации овечки с меткой не являются этим скином и не включены в активный manifest.

## Раскладка и разметка

Turnaround-листы: 4 столбца × 2 ряда, порядок **S, SW, W, NW, N, NE, E, SE**. S = вниз экрана, N = спиной вверх экрана. Камера неизменна, персонаж поворачивается на земле.

Ходьба: в каждом PNG 4 столбца-фазы. В goat-walk-a ряды **S, SW, W, NW**, в goat-walk-b — **N, NE, E, SE**. Цикл 0→1→2→3→0, рекомендованный старт 8 FPS. Все 32 кадра включены; никаких рядов старой овечки здесь нет.

`manifest.json` v3 содержит playerId=`goat`, role каждого дизайна, список кадров и точные измеренные `rect` [x,y,w,h]. `manifest.js` содержит те же данные для HTML. У ally только один кадр, direction=SE — не индексировать его по 8 направлениям.

Не разрезать PNG на произвольные равные 128px ячейки. Размеры новых листов перечислены в source-inspection.json. Измеренные промежутки между рядами/столбцами и source rectangles уже записаны. `sourceAnchor` — начальный нижний центр; `relativeScale` ходьбы одинаковый для четырёх кадров направления, чтобы не масштабировать тело независимо в каждой фазе.

## Подключение в текущий билд

Пока выполнены только генерация и подготовка передачи. Код игры, поведение и существующие игровые assets не менялись.

- В `js/painted-art.js` герой исторически рисуется через ключ **sheep**. Это старое имя слота, НЕ указание использовать овечку. Подключить новый козлик в этот слот или последовательно переименовать ключ в goat. Питомца sheep-pet туда не ставить.
- В `character` Facing имеет приоритет над Walk. Если одновременно создать goatFacing и goatWalk (или их алиасы sheepFacing/sheepWalk), нужно явно выбирать ходьбу при движении; иначе Facing подавит анимацию.
- Существующий порядок направлений: `(Math.round(angle/(Math.PI/4))+14)%8`, angle=atan2(dy,dx), экранная Y вниз.
- В текущем `WALK_FPS` герой идёт с 8 FPS. В новом пакете есть отдельный idle; не выбирать случайную фазу шага вместо стояния.
- `TILT=0.86`, `drawGoat` использует `scale(1,1/TILT)` и width=40. Высокий top-down ракурс уже нарисован; не наклонять PNG второй раз.
- `stamp`/`drawFrame` включают smoothing. Для новых пиксельных героев отключить `imageSmoothingEnabled`, восстановив старое значение контекста после рисования.
- При упаковке предложен virtual cell 128×128, origin [64,104], но точку опоры обязательно подогнать к теням. Старые Facing=0.81 и Walk=0.89 нельзя бездумно перенести на новую раскладку.
- clubman→bearer, mage→seer, hound→dog, brute→bearer+champion. Курица относится к prop. Крысоогр пока отрисовывается отдельно; при подключении сохранить прыжок, emerge и предупреждения атак.
- Мышь-торговец — дружественный визуальный образ для торговой роли. По этому запросу не менять механику магазина и не назначать новые боевые свойства союзникам.
- Отсутствие ошейника в PNG не означает удаление отдельного игрового эффекта талисмана из `drawGoat`.

## Качество и границы готовности

Исходники сгенерированы встроенным **image_gen**; полные промпты — `prompts.json`, происхождение файлов — `sources.json`. Визуально проверены козлик, направления и отсутствие цветной метки у питомца. Структурная проверка: все 124 выбранных кадра обнаружены, лежат внутри измеренных ячеек, углы PNG прозрачные. Это генеративные исходники с разметкой, а не финальные игровые атласы.

Перед production проверить на игровом размере: чистоту полупрозрачной каймы, единый шаг пикселя/палитру, стабильность тела в цикле и idle↔walk, pivot над тенью, руку оружия у врагов. В r3 сторона молнии выровнена и визуально проверена: S/E/SE отмечены, остальные направления без видимой метки. В походке остаётся небольшая вариативность позы головы; оценить плавность при интеграции.

Стиль и наклон сверены с предыдущим просмотром локального THE YARD. Новые изображения в сам игровой билд пока не вставлялись. Финальную читаемость проверить на THE YARD и THE TRIP при подключении.
